# موقع دعوة زفاف عربي — بداية مجانية

هذا مشروع بداية لواجهة دعوة عربية، مع قاعدة بيانات Supabase لاستهلاك رمز من 6 أرقام مرة واحدة.

## قبل النشر
- تحتاج حساب GitHub وحساب Supabase.
- أنشئ مشروع Supabase مجانيًا، ثم افتح SQL Editor وشغّل `supabase.sql`.
- انسخ Project URL و anon/public key إلى `config.js`. لا تضع `service_role` key في الموقع أبدًا.
- أضف صورتك باسم `assets/couple.jpg` وأغنيتك باسم `assets/music.mp3`.
- حدّث اسم القاعة والعنوان ورابط خرائط Google ورقم واتساب في `config.js`.
- ارفع الملفات إلى مستودع GitHub، ثم فعّل Settings > Pages > Deploy from a branch > main > /(root).

## تنبيه مهم قبل استخدامه مع ضيوف حقيقيين
هذه حزمة بداية وليست نظامًا جاهزًا للإنتاج بعد. وظيفة SQL تستهلك الرمز ذريًا، لكنها لا تنشئ روابط/رموز للضيوف ولا تطبق تحديد معدل المحاولات أو لوحة إدارة. لا تستخدم بيانات ضيوف حقيقية حتى تُضاف عملية إدارة آمنة وتحديد محاولات. كذلك فإن واجهة النموذج الحالية تحتاج أن تتلقى نتيجة ناجحة ثم تعرض الدعوة؛ يجب اختبارها بعد إكمال إعداد Supabase.

## رابط الدعوة
بعد إعداد نظام إنشاء الدعوات، سيكون الشكل مثل:
`https://YOUR-USERNAME.github.io/YOUR-REPO/?t=RANDOM_PRIVATE_TOKEN`

## قيود واقعية
- لا يمكن ضمان منع screenshot أو تصوير الشاشة بكاميرا أخرى.
- لا يمكن ضمان منع إعادة توجيه الرابط؛ الرمز الخاص ووقت الانتهاء يخففان ذلك فقط.
- تشغيل الموسيقى يحتاج نقرة من المستخدم في معظم المتصفحات.
- تأكد من امتلاك حقوق استخدام الأغنية والصور.
